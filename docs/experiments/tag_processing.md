# 實驗與方法評估

## 實驗主題：書籍標籤 (Tags) 的處理方式

為了優化檢索與推薦效果，本實驗探討如何處理書籍的標籤資料，目前規劃以下四種方法進行比較：

### 1. LLM 直接生成 + 硬性規則過濾 (Baseline)

- **說明**：LLM 直接生成欲篩選的標籤，再透過硬性規則進行過濾或評分。
- **特點**：為系統目前的基準 (Baseline) 做法。

### 2. 提供完整標籤集給 LLM + 硬性規則過濾

- **說明**：將系統中所有現有的標籤提供給 LLM 作為參考，讓其從中挑選或生成欲篩選的標籤，並同樣使用硬性規則過濾或評分。
- **特點**：確保 LLM 輸出的標籤皆為資料庫中實際存在的標籤，減少幻覺或無效匹配。

### 3. LLM 直接生成 + Embedding 相似度評分

- **說明**：允許 LLM 自由生成理想的標籤，接著透過 Embedding 計算 LLM 生成標籤與實際存在標籤之間的語意相似度，並以此相似度作為評分依據。
- **特點**：保有 LLM 的彈性，即使生成的標籤不完全吻合實際資料，也能透過語意空間找到最相近的對應標籤。

### 4. 標籤融入文本 Embedding (特徵融合)

- **說明**：將書籍的標籤直接與小說簡介合併，共同進行 Embedding 運算。
- **特點**：讓標籤直接影響語意向量提取的結果，從底層表徵改變語意搜尋 (Dense Retrieval) 的匹配邏輯。
