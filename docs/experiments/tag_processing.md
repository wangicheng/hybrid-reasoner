# 標籤處理實驗與方法評估 (Tag Processing Experiments)

## 核心引擎架構：雙軌評分 + 後置篩選 (Dual-Track Scoring + Post-Filtering)

本專案採用**語意相關性評分**與**硬性約束過濾**分離的架構：

1. **雙軌相關性評分 (Dual-Track Scoring)**：
    - **語意音軌 (Semantic Track)**：處理隱性氛圍、內容意圖。透過內容向量 (`text_vector`) 計算相似度。
    - **屬性音軌 (Attribute Track)**：處理標籤 (Tags) 的語意匹配，將標籤視為顯性屬性的語意強度。
2. **線性加權 (Additive)**：`Total = Score_Semantic * w1 + Score_Attribute * w2`
3. **後置篩選層 (Post-Filter Layer)**：處理硬性約束（負向標籤、作者、字數、完結狀態）。不符合者直接移除，不參與排序。

### 執行流程

## 實驗主題：標籤處理策略對比

探討在屬性音軌 (Attribute Track) 中，標籤效用應如何評估。以下方法僅差異在屬性音軌的處理邏輯：

| 實驗編號 | 方法名稱 | 處理邏輯 | 特點 |
| :--- | :--- | :--- | :--- |
| **Exp 1** | **Baseline** | LLM 生成標籤 + SQL 模糊比對 | 基準線，依賴字面相似度 |
| **Exp 2** | **Guided LLM** | 提供完整標籤集供 LLM 參考 | 減少幻覺，提升標籤命中精準度 |
| **Exp 3** | **Individual Mapping** | 標籤面向映射 + MaxSim 語意匹配 | 識別語意關聯（如「系統流」→「系統」），不被標籤總數稀釋權重 |
| **Exp 4** | **Feature Fusion** | 標籤融入文本 Embedding | 模糊雙軌邊界，將顯性屬性隱性化 |
| **Exp 5** | **Joined Vector** | 標籤全域向量空間搜尋 | 使用標籤集整體向量進行語意檢索 |

## 評估機制 (Evaluation)

採用 **LLM-as-a-Judge** 進行自動化品質評估 (`src/eval/llm_judge.py`)。

- **核心指標**：**NDCG@10** 衡量排序品質。
- **評判標準 (0-3 分)**：
  - **3 分 (Highly Relevant)**: 完美符合核心需求與隱性偏好。
  - **2 分 (Partially Relevant)**: 符合部分關鍵需求。
  - **1 分 (Marginally Relevant)**: 僅有邊緣關聯。
  - **0 分 (Irrelevant)**: 完全不符或包含致命排斥條件。
- **負向條件處理**：由「後置篩選層」強制執行。任何命中排除條件的書籍均不進入評估階段，確保結果 100% 符合硬性約束。
