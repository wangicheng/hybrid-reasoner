# Gemma 4 PermSC List-wise Reranking 實驗報告

## 1. 實驗總結

本次實驗採用了最新的論文技術：**Permutation Self-Consistency (PermSC)** *(Tang et al., 2024)* 來解決 LLM 在 List-wise 重新排序時嚴重的「位置偏差 (Position Bias)」與「Lost in the middle」問題。

相較於單純依賴單一排序，PermSC 會對 100 本候選書產生不同的排列組合 (例如：正序、倒序、隨機打亂)，分別讓 LLM 進行排名預測。接著透過 **Borda Count 聚合演算法 (Borda Aggregation)** 對這 3 組不同的排名結果進行計分與融合，找出在各種順序下表現最為穩定的「中央排序 (Central Ranking)」。

這不僅嚴格控制了 API 的呼叫次數 (每筆 Query 僅 3 次)，又達成了學術級別的位置偏差消解。
