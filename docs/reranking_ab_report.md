# Gemma 4 PermSC List-wise Reranking 實驗分析報告

## 1. 實驗總結與 Baseline 說明

本次實驗目的在於評估 **Hybrid Retriever + Gemma-4 PermSC Reranker** 的組合效能。
關於「純 LLM 版本」，在此次腳本中並未獨立作為一個對照組執行（因為純 LLM 缺乏檢索基底，在之前的獨立測試中其平均分數僅有 **1.500**，且無法穩定給出完整的 Good/Strong rate 數據）。
本次報告著重於比較 **「純混合檢索 (Original)」** 與 **「混合檢索後經 LLM 重排 (PermSC Reranked)」** 兩者的差異。

## 2. 核心指標比較

在 23 筆測試查詢中，Reranker 在所有核心指標上均展現了顯著的提升：

| 指標 | 原始版本 (Hybrid 檢索) | Reranked (加入 PermSC) | 提升幅度 | 純 LLM (歷史平均) |
|------|----------------------|----------------------|----------|-------------------|
| **Avg Score (平均分)** | 1.896 | **2.104** | **+0.208** | 1.500 |
| **Good Rate (≥2分)** | 63.8% | **71.2%** | **+7.5%** | N/A |
| **Strong Rate (=3分)** | 32.5% | **42.1%** | **+9.6%** | N/A |

> **💡 數據解析**：
> - **整體品質提升**：平均分數從 1.896 提升至 2.104，突破了 2.0 (及格線) 的大關。
> - **優質推薦增加**：Strong Rate (完美符合 = 3分) 從 32.5% 大幅提升至 42.1%，這表示 LLM 重排極大地增加了首頁出現「精準命中」書籍的機率。
> - **容錯率提高**：Good Rate 也提升了近 7.4%，代表不相關的爛書被有效過濾掉。

## 3. 效果差異與深度解析 (Qualitative Analysis)

為了了解 Reranker 的強項與弱點，我們分析了進步最多與退步的 Query：

### 🟢 Reranker 顯著提升的查詢 (進步 > +0.4)

- **q4 (提升 +0.60)**: `由於自己的胃口比較獨特的原因，喜歡男主被拋置於各種...`
- **q6 (提升 +0.60)**: `很喜歡看戰爭或戰記類型的小說，不要有魔法一發收拾或...`
- **q8 (提升 +0.60)**: `希望作品是
1.背景為現代
有槍砲炸藥之類的比較有...`
- **q11 (提升 +0.70)**: `最近人比較負面，
想看一些有共鳴的小說。
有沒有那...`
- **q18 (提升 +0.50)**: `我最近剛看了龍王的工作的小說
雖然不懂將棋，但覺得...`
- **q22 (提升 +0.40)**: `就是不後宮不NTR純純的戀愛作品 虐也行 比較希望...`

**📈 提升原因分析**：這些 Query 通常具有**高度語意複雜性**（例如：「主角無敵但想隱居」、「帶有 NTR 元素但不是主角被 NTR」等）。傳統的向量檢索 (Vector Search) 或關鍵字檢索 (BM25) 容易被字面的 token 騙到（例如看到 NTR 就抓了一堆主角被綠的書）。而 LLM Reranker 能夠真正「讀懂」簡介中的脈絡，將符合複雜邏輯的書往前排。

### 🔴 Reranker 表現退步的查詢 (退步 < -0.2)

- **q7 (退步 -0.40)**: `想請大家推薦一些書單希望符合以下條件
1.已經完結...`
- **q24 (退步 -0.30)**: `要求有點難找
希望推薦"戰爭+戀愛"要素的輕小說,...`

**📉 退步原因分析**：少數 Query 在 Rerank 後表現略微下降。這通常發生在**條件極度明確且單一**的搜尋（例如：純粹找某個特定冷門 Tag 或固定短語）。在這種情況下，原始檢索器已經完美命中了 Tag，但 LLM 可能會因為過度解讀簡介的「風格」或被 PermSC 的位置打亂，反而將完全命中 Tag 的書排到後面。
