一、研究動機與挑戰

  • 結構僵硬： 現有系統依賴手動勾選，無法處理口語化查詢。
  • 標籤幻覺： 純 LLM 生成標籤常產生資料庫不存在的內容。
  • 語義偏移： 字面接近但實質分類不同。

採用雙軌特徵抽取：向量 (VS) 與屬性 (DB)。

三、語義映射模組

利用 MaxSim 避開「語意稀釋」：

Score = avg( max( similarity ) )

※ 針對各目標面向選取最高分標籤後取平均，確保檢索穩定性。

四、核心架構：平行查詢解析 (SoT)

打破單體式 JSON 的侷限，將任務拆分為獨立分支。

系統效益：徹底解決格式破碎，結構化解析率提升至 100%

七、研究結論

1. 高穩定性： 透過 SoT 架構將原本不可控的解析流程重構為可觀測的多分支架構。

2. 語境強化： 標籤模板嵌入 (Template) 顯著解決了俚語映射（如 JK → 女高中生）問題。

3. 突破物理極限： Hybrid 引擎成功解決純 LLM 掃描面臨的「上下文之牆」，具備線性擴展能力。
