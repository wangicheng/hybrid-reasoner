# Reranker候選數量消融實驗統計分析

分析日期: 2026-05-19
實驗數據目錄: `data/experiments/runs/batch_cl_ablation_all`
分析模型: cl20, cl30, cl40, cl50, cl75, cl200

本報告旨在透過**配對t檢定 (Paired t-test)**，分析不同Reranker候選數量（cl20至cl200）對模型各項評估指標（NDCG, Precision, Recall, F1-score @10, Latency）的影響是否具有統計顯著性。

p-value < 0.05 通常被認為差異是**顯著的**，代表觀測到的性能變化很可能不是由隨機因素造成的。

- **結論**: 對於 `NDCG` 指標，`cl75` 似乎是成本效益較高的設定點。
