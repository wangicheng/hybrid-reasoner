# 標籤嵌入語義強化策略實驗報告 (Tag Embedding Semantic Enhancement)

本實驗旨在探討如何透過**語境模板 (Context Templates)** 與**標籤說明文字 (Tag Descriptions)**，提升搜尋引擎將使用者的口語化文字精準匹配到資料庫標籤的能力。

## 1. 實驗背景與目的
在小說搜尋系統中，使用者輸入的關鍵字（如「想看主角很強的」）需要被正確映射到系統標籤（如「龍傲天」）。傳統做法是直接比對標籤名稱的向量，但這往往忽略了標籤背後的深層含義。

本實驗測試了三種不同的嵌入 (Embedding) 策略，探討加入**標籤說明文字**以及**混合權重計算**是否能顯著提升匹配精準度。

## 2. 實驗設定
- **測試模型**：`gemini-embedding-001`
- **測試規模**：
    - **標籤池 (Candidates)**：61 個核心內容標籤（如：轉生、鬥智、大逃殺、復仇等）。
    - **測試查詢 (Queries)**：408 筆針對這些標籤的口語化或變體描述文字。
- **標籤說明文字**：為 61 個標籤撰寫了約 50-100 字的定義與特徵描述。
- **查詢任務類型**：`RETRIEVAL_QUERY`
- **候選任務類型**：`RETRIEVAL_DOCUMENT`

## 3. 測試策略描述

### 策略 A：對稱模板策略 (Symmetric Template - 基線)
這是目前公認效果最好的方法。將查詢文字與標籤名稱都套入同一個「語境模板」中。
- **查詢側**：`這部作品的類型偏向{使用者文字}`
- **標籤側**：`這部作品的類型偏向{標籤名稱}`
- **特點**：強調「格式對齊」，讓模型在相同的語義空間中比對名稱。

### 策略 B：帶說明的非對稱策略 (Asymmetric with Description)
將標籤的定義直接加入嵌入文本中。
- **查詢側**：`這部作品的類型偏向{使用者文字}`
- **標籤側**：`標籤名稱：標籤詳細定義文字`
- **特點**：讓模型理解標籤的深層含義，而不僅僅是匹配名稱字面量。

### 策略 C：混合權重策略 (Hybrid Weight - 最終方案)
將上述兩種策略的得分進行比例融合。
- **計算公式**：`最終得分 = (策略 A 得分 * 0.7) + (策略 B 得分 * 0.3)`
- **特點**：兼顧「標籤名稱的精準對齊」與「說明文字的語義深度」。

## 5. 核心結論與洞察

### 1. 混合權重是目前的「最優解」
純粹加入說明文字（策略 B）雖然能提升模型對標籤的「理解力」(Macro-F1 顯著提升)，但會因為文字量較大而稀釋了標籤名稱本身的權重，導致 Top-1 準確度下降。而**混合策略 (策略 C)** 成功抵消了這個副作用，準確度直接從 83% 跳升至 **88.5%**。

### 2. 說明文字具有「消歧義」的作用
在實驗中發現，當系統同時存在多個相似標籤（例如「青春」與「青春日常」）時，對稱模板容易產生混淆。說明文字的存在提供了額外的特徵（如：是否包含校園瑣事、是否強調夢想等），幫助模型在極其接近的候選者中做出正確判斷。

### 3. 查詢模板的穩定性
實驗再次驗證了 `這部作品的類型偏向{label}` 是一個極其強大的查詢語境，它能有效引導 `gemini-embedding-001` 模型將注意力集中在「題材分類」的語義維度上。

3. **模型升級驗證**：在相同的混合策略下，驗證 `models/gemini-embedding-2-preview` 是否能達成 90% 以上的 Top-1 準確度。
